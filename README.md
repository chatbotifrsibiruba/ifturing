# IFTuring — Assistente Virtual para o Processo Seletivo do IFRS Campus Ibirubá

> Projeto de pesquisa, ensino e extensão do IFRS Campus Ibirubá  
> Código SIGAA: PVH4343-2025 · Vigência: abril a dezembro de 2026

---

## Sobre o projeto

O **IFTuring** é um assistente virtual (chatbot) desenvolvido para responder dúvidas de candidatos sobre o processo seletivo do IFRS — Campus Ibirubá. O sistema utiliza a arquitetura **RAG (Retrieval-Augmented Generation)**, que combina busca semântica em documentos reais com geração de respostas por um modelo de linguagem (LLM), reduzindo alucinações e garantindo respostas baseadas nos editais oficiais.

O projeto é estruturado sob o princípio da **indissociabilidade entre Pesquisa, Ensino e Extensão**, conforme o Edital Conjunto nº 07/2025 — Fomento Interno para Projetos Indissociáveis do IFRS.

---

## Motivação

O processo seletivo do IFRS abrange múltiplos níveis de ensino e envolve regras complexas sobre cotas, isenções e documentação. Candidatos frequentemente têm dúvidas que sobrecarregam os canais de atendimento do campus, limitados ao horário convencional. O IFTuring nasce para oferecer suporte informacional **24 horas por dia, 7 dias por semana**, de forma acessível e precisa.

---

## Objetivos

### Geral
Desenvolver um assistente virtual para o processo seletivo do IFRS — Campus Ibirubá, integrando de forma indissociável as dimensões de pesquisa, ensino e extensão.

### Pesquisa
- Desenvolver a arquitetura de software baseada em RAG para o assistente virtual
- Analisar a acurácia e a eficácia do chatbot na resolução das dúvidas dos candidatos
- Mapear e categorizar as principais dificuldades informacionais dos candidatos

### Ensino
- Capacitar os estudantes envolvidos em tecnologias de IA, LLMs e desenvolvimento de software
- Proporcionar experiência prática em um projeto tecnológico completo, da concepção à implementação
- Articular os conteúdos do projeto com componentes curriculares dos cursos de tecnologia do campus

### Extensão
- Disponibilizar o assistente virtual à comunidade externa como ferramenta de suporte 24/7
- Realizar no mínimo 3 oficinas em escolas públicas de Ibirubá e região para promover a literacia digital
- Produzir material informativo (folders, posts) para divulgar o chatbot junto à comunidade

---

## Funcionalidades previstas

- Respostas baseadas nos editais oficiais do IFRS (isenção, cotas, ingresso, EJA, indígenas, superiores)
- Filtro de FAQ antes do processamento pelo LLM
- Sistema de feedback dos usuários
- Escalada para atendente humano quando necessário
- Interface conversacional via Telegram (setembro a dezembro de 2026)
